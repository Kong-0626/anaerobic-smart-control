# 厌氧发酵酸积累智能调控系统

基于酸积累分级调控原理制作的交互式前端演示页面。

## 页面功能

- 系统总览、实时监测、诊断分析与智能调控
- 稳定、早期预警、失衡补碱、红线预警四类演示场景
- VFA、ALK、pH、CH₄/CO₂ 与产气量趋势展示
- 分级触发逻辑、补碱剂量计算及复测节点
- 参数沙盘与调控工单交互
